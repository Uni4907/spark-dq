# CSV 和检测统计口径

## 输入

本阶段限定 UTF-8（允许 BOM）、RFC4180 逗号 CSV、最多 20 MiB、最多 100 列、单元格最多 65536 字符；必须有表头和数据。支持双引号转义、引号内逗号和换行。空白物理行忽略；引号中的空字符串保留。数据类型统一为字符串，不自动转换数值（001 与 1 不相同）。

字段名区分大小写，必须匹配 `[A-Za-z][A-Za-z0-9_]{0,63}` 且唯一。首字符不能是下划线，内部 `__dq_` 列名不会冲突。不根据浏览器 MIME 判断 CSV；完整解析内容后注册。前 10 条数据仅作预览，不替代 Spark 检测。

## 空值

Spark CSV 指定 `nullValue=\N`、`emptyValue=""`，不自动移除首尾空格。

| 指标 | 口径 |
| --- | --- |
| nullCount | Spark 中为 null，包括未加引号的缺失单元格和字面标记 `\N` |
| emptyCount | 非 null 且长度为 0，例如带引号的 `""` |
| whitespaceCount | 非空字符串，经 Spark `trim` 去除两端普通空格 U+0020 后长度为 0；不把制表符等所有 Unicode 空白自动视为空 |
| blankCount | 以上三项之和；异常文件包含这三类记录 |

CSV 无原生 SQL NULL 类型，`\N` 是本系统约定；带引号的 `"\N"` 也作为 null。null 与空字符串在异常 JSON 中分别保留为 `null` 和 `""`。空值规则按所选字段分别建立，每条规则有独立 ID。同一条记录可能同时违反多条规则，各规则异常数不能直接相加作为唯一异常记录数。

## 重复

按用户选择的一列或多列业务键进行 Spark 分组，使用字符串原值精确比较，区分大小写、不 trim。业务键为 null 时仍参与分组；同一组合中的 null 与 null 视为相同分组键。

- duplicateGroups：记录数大于 1 的业务键组数。
- duplicateRows：这些组中所有记录的数量，包含每组第一条。
- excessRows：每个重复组的 `count - 1` 之和，即 `duplicateRows - duplicateGroups`。

异常明细输出所有重复组成员，增加 `__dq_group_size`；不指定“删除哪一条”，不自动清洗。数据没有稳定行号，异常预览顺序不保证为原文件顺序。

## 文件与状态

上传后 `/data/raw/{datasetId}.csv` 以 UUID 名称保存并设置只读，MySQL 保存路径、SHA-256、大小、行数、字段与小型预览。异常明细位于 `/data/tasks/{taskId}/anomalies/{ruleId}/part-*.json`，结果汇总先写临时文件再原子重命名，日志保留为 engine.log。API 预览每规则最多 50 条。

任务正常状态为 QUEUED → RUNNING → SUCCEEDED / FAILED；主动取消时 QUEUED → CANCELLED，或 RUNNING → CANCELLING → CANCELLED。单工作线程、最多 8 个等待任务，每任务独立 Spark JVM、local[2]、1 GiB 堆、300 秒超时。耗时为运行阶段墙钟时间，包含 Spark 启动、计算与异常文件写入，不含排队。

数据集、任务、规则、结果各有独立 UUID；所有规则结果及任务成功状态在一个 MySQL 事务中提交。任务失败保存原因和耗时，已有异常临时文件保留用于排查但不作为成功结果提供。正常停止会终止计算子进程；异常重启时把遗留 QUEUED/RUNNING 改为 FAILED 并记录中断原因，用户可重新提交。

本阶段仅支持一个后端实例。文件原子移动与 MySQL 提交不属于跨资源事务；若数据库在注册时失败，文件可能作为未注册孤立文件保留，后续增加对账工具，不自动删除原始文件。schema.sql 只做非破坏性建表，后续结构升级应增加迁移工具。


## csv-v2 与治理版本

新任务使用 csv-v2，以 RFC4180 双引号转义解析 CSV；csv-v1 历史任务复检使用原读取方式。治理只接受成功的 csv-v2 任务，旧任务需对数据集新建检测后再治理。

空值移除针对来源任务中全部 MISSING 规则，以 OR 合并命中条件，移除整条记录。之后按 DUPLICATE 规则业务键分组，使用所有字段字典序（NULL 在前）保留一条，不以数据输入顺序、时间或业务优先级推断最优记录。原文件不修改，输出为独立版本。

写出时保留空格、引号、逗号和换行；空字符串写为带引号空字段，NULL 写为约定的反斜杠 N。统计基于序列化 CSV 重新读取后的实际记录。全删结果合法，保留表头与字段，行数为零。

报告同时给出前后记录数与每条规则指标。不同规则可能命中同一记录，不能合计为全局异常行数；删除异常记录导致的指标下降不等于修复原始单元格。减少量为之前减之后，负值表示该规则指标恶化。

## 高级规则与模板

TYPE/RANGE/REGEX 跳过缺失、空字符串和纯空格，记录 checkedCount/skippedBlankCount/invalidCount。RANGE nonNumericCount 为 invalidCount 子集，边界包含且精度为 28 位整数/10 位小数；REGEX 为 Java 整字段严格匹配。定义版本为 1，冻结参数与模板修订，报告同时匹配类型、字段和参数。完整口径与验收见 [规则管理](rules.md)。

## 治理策略 v2

按字段标准化后填充，随后移除仍缺失记录并按处理后的键去重。填充仅覆盖 NULL、空字符串及纯普通空格，不覆盖非空值；填充值不会在本次处理再次标准化。标准化若产生保留空值标记则停止任务，避免 CSV 重读失真。逐操作 changedRows 是该阶段空值安全比较的实际差异，操作间可能重叠，不能相加为唯一受影响行数。历史无审计任务返回 null，详见 [填充与标准化](governance-transforms.md)。

## 取消与历史分页

主动取消与成功登记通过任务行锁仲裁；确认计算进程退出后才标记 CANCELLED，无成功结果或治理版本。CANCELLED 可按快照复检，重启完成遗留 CANCELLING 清理；其他未结束任务仍标记 FAILED。分页单次请求的总数/记录共享只读事务，按 created_at/id 倒序；跨页新增或状态变化可能移动 offset 页。具体接口、测试与边界见 [可靠性记录](reliability.md)。

## 存储维护

离线只读对账核对数据文件 SHA/大小、异常结果分片和快照指纹；失败/取消任务的诊断文件保留。备份同时保存业务库、文件卷和实际应用 JAR，恢复只创建新卷并核对全部归档条目，要求空闲维护窗口。实现、真实验收与同机镜像限制见 [存储记录](storage.md)。
