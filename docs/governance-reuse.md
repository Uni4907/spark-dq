# 复用历史成功治理策略

在成功检测任务详情展开“生成新的治理版本并自动复检”→“复用历史治理策略”。按数据集名称或任务编号查找历史成功策略，点击“带入并替换当前配置”。仅替换表单，不会立即执行；支持修改和“撤销带入”。检查后使用原“生成独立版本并复检”执行。

成功治理策略已经随历史任务保存，本轮复用它们，不新增独立策略表。列表分页显示成功且实际生成版本的治理任务，普通检测、失败和取消任务不参与。名称和任务编号按字面搜索，含中文及特殊字符；默认每页5条。

仅复制治理配置，不复制检测规则。空值移除和业务键去重按照当前任务的空值字段与业务键执行；请核对当前规则。标准化、填充、映射和保留顺序均需适配当前有效输入版本的字段；目标本身是治理任务时，有效输入为它生成的版本。旧口径/未成功目标、字段不兼容或缺少所需空值/重复规则会被拒绝，拒绝不替换表单。

## API

- GET /api/governance-policies?page=1&pageSize=5&q=关键词：只读分页，默认pageSize20、最多100，q最多200字符。使用稳定倒序及绑定参数，计数/列表共享只读数据库快照。
- GET /api/governance-policies/{sourceTaskId}?targetTaskId={targetId}：只读兼容校验，返回来源信息、目标有效数据集ID与规范化策略副本。不会创建任务、修改策略或数据文件。
- 真实执行仍使用既有POST /api/tasks/{targetId}/govern；最终实际策略冻结在新治理任务中，原历史策略不变。

非治理来源、未成功来源/目标或旧口径目标409，字段/规则不适配400，任务不存在沿用404。规范化沿用v2/v3/v4原约束，不扩大操作能力或字段限额。带入后修改嵌套映射和优先级不会反向修改来源对象。

## 范围

这是历史成功策略复用，不是命名模板CRUD/修订/归档，也不保存尚未执行的草稿。带入来源在当前界面展示；新任务保存最终实际策略及当前检测来源，未新增专门的策略复用来源引用字段。无数据库迁移，不改变现有备份表集合、20MiB或300秒预算。
