# 可阅读与打印的质量报告

工作台任务详情新增“阅读 / 打印质量报告”“下载离线HTML”和原有JSON入口。成功任务展示实际检测结果、规则配置、可用的前后对比、治理策略/操作审计、输入和版本SHA；失败/取消任务显示处理记录，不显示成功质量统计。历史缺失快照/审计明确标注未记录，不补零或造分数。

独立HTML文件内含样式，无外部字体/图片/脚本，不依赖服务持续在线即可阅读。打开后使用浏览器打印（Ctrl+P），选择打印机或另存为PDF。包含A4打印样式、重复表头和换页规则；没有新增服务端PDF引擎，本轮未自动生成或声称验收实体打印机输出。

## API

- GET /api/tasks/{id}/report.html：UTF-8内联HTML，终态任务可读。
- GET /api/tasks/{id}/report.html?download=true：相同字节的离线附件。
- GET /api/tasks/{id}/report：原JSON接口保持。
- 未结束409，不存在404；沿用Reports原统计和来源比较口径，不写任务或数据集。

HTML值统一转义，响应提供no-store、nosniff和限制资源加载的CSP。报告不直接输出服务端文件路径，不给出未配置字段的合格承诺；异常行数不能跨规则相加，减少记录不等于修复值，前后恶化的负减少值保留。

## 构建与验证

使用原README锁定Maven/Node镜像完成Maven package与前端build，再在新隔离环境运行；本功能不需要数据库迁移或改变20MiB/300秒限制。Java新增ReportDocumentsTest八项，覆盖实际统计/中文、HTML转义、失败取消抑制旧指标、负变化/不可比较、治理策略审计、历史缺失、HTTP头/附件与状态码。不要仅凭测试数宣称业务可用；本阶段另有真实Spark检测→治理→复检及页面报告验收。

部署按cluster-lab.md为新候选指定后端/前端本地镜像引用；主部署未自动替换。详细实测和运行入口见当前完整进度。
