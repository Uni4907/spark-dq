修复前证据：原版正常快速网络下，16秒采样没有捕获到布局高度变化；为稳定复现，使用只读本机代理增加220毫秒接口延迟，未改原版代码、响应内容或数据库。随后605帧采样中81帧出现加载提示，历史区域高度在573.646和606.042像素之间变化，结果区 top 在1488.104、1520.500和1552.896像素之间变化，最大差64.792像素。见 `before-delay-dom.json`；无延迟对照见 `before-dom.json`。

旧图表 canvas 在采样窗口内没有被替换。因此主因是布局中的周期性提示插入，并非已证实的整页销毁。重复图表配置是源码确认的次要重绘风险，本轮没有将旧动画逐像素量化为独立的肉眼主因。

其余审计：未发现随机 key、轮询前清空整个列表、全局遮罩、周期性字体加载或整页 CSS 动画。dataset.id / task.id 的 key 用于用户真正切换对象；保留这些业务边界。新界面用 v-show 切换工作区，避免导航本身销毁表单。重新点击当前数据集/任务也不清空草稿和异常预览。

## B. 刷新与失败恢复

- 活跃 QUEUED / RUNNING / CANCELLING 约3秒检查，静置约15秒，后台标签页约30秒；保持轮询，未通过关闭更新掩盖问题。
- 定时器在请求结束后安排下次检查，保留每个列表/详情的序号或 owner；失败请求保留上次成功数据。新任务、导入等操作会重新安排活跃刷新节奏。
- 后台更新不触发全页 loading，不反复清空表格或成功报告；状态真正改变时才发布新数据。
- 全局操作通知和连接错误使用固定局部反馈区域，不推移业务内容；局部导入错误继续就近解释。
- MySQL 导入完成后提示选择快照，保留用户当前数据集及规则草稿；仍可使用明确按钮进入该快照。

真实断连测试：先确认队列空闲，再仅停止候选后端。失败期间，结果区高度保持1825.542像素，5行结果/预览表格保持，滚动位置348像素保持，图表实例 `ec_1792632730364` 保持；恢复后错误自动消失，以上值再次一致。见 `network-recovery.json` 和 `network-failure.jpg`。测试中曾临时调整窗口后恢复原尺寸，记录已明确标注。

## C. 界面升级

采用浅色工作台、白色卡片、蓝色主操作、固定侧栏和顶部工作区，按概览、数据集、规则、任务与报告、治理版本、运行状态组织现有能力，未新增不必要路由。

概览只使用真实分页 API 的数据集总数、任务总数和最近任务状态，不将当前筛选页数量当全局统计，不编造合格率或质量分数。数据接入分组展示 CSV、原生 Parquet、MySQL 快照和预置文件；Hive 来源在真实快照追溯中保留。

“注册多份 CSV 分片”改为“注册 CSV 分片”，使用36像素级次级操作，与上传 CSV 对齐；新增可搜索的数据集目录和局部滚动表格。CSV 约束、来源指纹与完整文件下载保留，通过渐进展开降低默认页面噪声。

规则工作区保留所有类型、字段、参数、默认值、模板和历史修订。IQR/FD 增加就近语义说明，完整精度/空值说明保留。桌面任务区采用列表与详情双栏，窄屏顺序布局。报告保留所有实际指标与技术说明；IQR 前后 Q1/Q3/IQR/上下界使用精确文本对比表，完整指标可展开；FD 明确展示全部冲突参与行，未将其描述为全部错误来源。

治理入口、策略复用、映射、填充、保留优先级、父子版本、审计、前后比较和独立复检均保留。突出原始数据不覆盖。按钮、输入、状态、分页、空状态、错误和间距统一使用共享样式与颜色变量，保留清晰键盘焦点及减少动态效果设置。

## 候选操作与保护

在WSL中执行（仓库 `/home/sparkdq/projects/spark-dq`）：

```text
python3 infrastructure/ui_candidate.py status
python3 infrastructure/ui_candidate.py start --minutes 120
python3 infrastructure/ui_candidate.py stop
```

start 验证配置、镜像和JAR身份，保留所有候选数据并设置有时限的自动停止；仍有活跃任务时不强制截断。stop 不删除卷或网络；队列不空时要求先在候选页面取消或等待。到期后可再次 start。Windows/WSL关闭后需重新启动本机环境。候选包含本轮合成测试历史与失败/取消记录，这些是验收证据。

所有实验、代理、业务库仅绑定本机或容器私网；未开放公网、采购资源、删除卷、执行全局清理、覆盖旧交付备份或运行无关500万行实验。15174镜像未替换，15173未发布。

## 已知问题、边界与发布建议

1. 主JS仍有Vite大于500kB的非阻断体积提示，后续可按图表/规则区做拆包；当前无新增外部依赖、CDN或高频动画。
2. 主要面向桌面；390px已验证局部滚动与无整页溢出，仍不是所有移动设备和所有浏览器的完整认证。
3. 静置是超过5分钟的本机真实浏览器验收，不替代长期生产监控。当前已解决可复现的周期性布局闪动，不宣称所有未来网络/浏览器组合绝不会抖动。
4. 构建验证首轮尝试覆盖镜像内root生成的dist被运行用户权限拒绝，后改用独立/tmp输出目录成功；日志保留。测试环境首轮文件挂载目录、SQL NULL样本和动态API端口记录也分别修正，未因此修改产品后端。
5. 建议进入正式发布准备：以上述前端与T11已验证后端应用为目标，在明确批准后按既有备份/维护/回滚流程切换。当前没有执行主切换，也没有把新候选覆盖到15174固定演示。
