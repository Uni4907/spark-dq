# 数据集任务历史、版本导航与质量变化

选择一个数据集后，工作台在数据/规则及全局任务列表下方展示“此数据集的任务与版本”。任务按时间/编号倒序分页，每页5个，可按状态筛选，每5秒更新。父版本、直接派生版本及其治理任务可跳转，不需从全局列表查找。

## 关联定义

- “检测 / 复检此版本”：普通任务以所选数据集为输入。
- “以此版本治理”：治理以此版本为输入，结果行数注明属于生成的治理版本。
- “生成此版本”：该治理任务以父数据集为输入，但输出是所选版本，也必须纳入所选版本历史。

同一治理任务在原始版和生成版的各自历史中可出现，各自页内只出现一次。失败/取消治理没有生成版本时，只属于输入版本；不把相同SHA的无关数据集混为同一身份。空历史、空筛选、加载失败/重试均有明确展示。

点击成功任务“查看质量变化”，读取既有JSON报告的来源对比：逐条显示规则/参数、前后异常行数和减少值。仍由Reports判定来源成功/口径兼容及按定义/参数匹配；没有可比来源则说明原因，不补零。负减少值标为异常增加，不对规则求总分，也不把移除记录称为修复原值。查看来源任务、完整HTML报告和生成版本的入口同时保留。

本功能不是任意两次任务比较器、跨全部分支的递归血缘图或质量趋势评分。版本导航仅直接父/子；当前数据集详情原接口的直接子版本列表仍未单独分页，超大版本家族可在后续优化。

## API

GET /api/datasets/{id}/tasks?page=1&pageSize=5&status=ALL

返回既有Page结构items/total/page/pageSize/totalPages；pageSize默认20、最多100。支持原任务状态枚举。先验证分页/状态/ID，再检查数据集存在；无效参数400，不存在数据集404。已存在但无关联任务是空页200。越界页保持请求页号及空items，前端自动回到有效页。

每项沿用任务基本字段，新增关联查询输出字段governance_id、output_dataset_id、parent_task_id及dataset_name。dataset_id始终是实际输入身份，不将其改写成当前筛选ID。状态条件作用于“输入匹配或输出匹配”整体；预编译参数、唯一治理关联、稳定排序和只读REPEATABLE_READ保证页内计数/记录口径一致。原全局任务/分页接口不变，无数据库迁移。

前端为历史分页及报告读取分别维护请求所有权；切换页/筛选/数据集或卸载时，旧响应不能覆盖新视图。版本元数据与历史刷新，不会因后台刷新重置左侧规则配置。业务仍是Java/Spark，新增组件只查询持久化结果。
