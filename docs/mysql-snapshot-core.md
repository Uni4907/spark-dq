# T1-A：MySQL 业务快照读取核心

2026-10-21。本批交付底层读取原语 `MysqlSnapshot` 和隔离测试；**T1 整体尚未完成**。该类未注册为 Spring 服务，没有新增 HTTP 入口，不在主部署启用，也不声明完成“界面/API → 检测 → 报告 → 复检”。当前技术路线见 [架构](architecture.md)。

## 数据与资源契约

- 调用方提供可信的表/字段白名单 `Table`，选择只能来自白名单，源字段可用中文；显式映射到现有英文字段命名规则。仅允许单表，无任意 SQL、连接或客户端 URL。
- 首批仅支持 InnoDB 普通表，单连接 `REPEATABLE READ / WITH CONSISTENT SNAPSHOT / READ ONLY`。先对源表取得元数据锁，再验证引擎；读取期间保持事务，不支持视图、MyISAM、多连接分区或跨表快照。
- 支持整型（含 unsigned）、DECIMAL/NUMERIC、DATE、VARCHAR/TEXT 系列。大整数按精确字符串，小数 `BigDecimal.toPlainString()`，DATE 按 `LocalDate`；拒绝浮点、时间戳、位、二进制、JSON、ENUM/SET、CHAR 等未经定义类型。无效/零日期由连接配置拒绝，禁止自动改成 NULL。
- SQL NULL 输出保留标记 `\N`，空串输出 `""`；保留普通空格、中文、引号和换行。字符串字面 `\N`、NUL、超长单元格拒绝，避免 CSV 重读有损。重复记录全部保留。
- 参数限制：1..100万行、1..20MiB、1..300秒、最多100列、单元格最长65536 Java字符。查询多读一行以判定超限，绝不将截断子集发布为全表快照。文本在 SQL 投影中最多返回65537字符用于拒绝超长值，避免驱动缓存整个巨大 TEXT 值。
- Connector/J 逐行流式读取；总时限定时器和主动取消均中止专属连接。**调用方连接工厂必须配置 connectTimeout/socketTimeout/zeroDateTimeBehavior**，核心无法强制第三方工厂的建连时间；正式 API 接线前必须用固定工厂封装落实，禁止透传客户端 JDBC 参数。
- CSV 与不含凭证的来源 manifest 在新临时目录中完成；关闭连接、结束只读事务、计算 SHA-256、设只读后原子移动到全新目标目录。失败不创建最终快照目录；只尝试移除本次生成的临时文件，历史目标不覆盖。文件系统拒绝清理时可能保留 pending 目录，未来状态机须显式记录清理失败，不能发布成功。
- manifest 保存独立导入ID、库表、字段映射、源类型、隔离级别、行数/字节和内容指纹。没有伪造 MySQL 可跨连接复用的快照 ID。无 ORDER BY 的表行顺序不保证稳定，相同逻辑数据重导入的文件哈希可能不同；业务等价必须比较完整多重集。

## 本批验证

`MysqlSnapshotTest` 覆盖白名单/SQL 名称、资源参数、精确数字、空白、非法类型、文本保真边界、字节上限、错误脱敏及目标保护。

`MysqlSnapshotIntegrationTest` 使用全新 MySQL8.4.8容器、内部独立网络/卷及仅有指定表 SELECT 权限的账号。覆盖真实读取、精确 CSV 字节、重复行、错误凭证、行数/字节超限、只读权限、源更新后旧快照指纹不变、快照建立后数据 SELECT 之前并发提交的隔离性、阻塞 JDBC 的实际取消和定时超时、保留空值标记拒绝、非事务表拒绝以及超长文本拒绝。部分分支测试通过控制器直接触发超时；另有真实定时器阻塞测试，二者分别存在。

复现工具：`python3 infrastructure/mysql_snapshot_trial.py`（需按项目说明在专用 WSL 中以具备 Docker 权限的用户执行）。运行前确认资源余量；新建运行目录，不重用业务库。Maven 离线使用项目既有缓存；未命中缓存应明确失败并保留日志，不自动修改主部署。

首次试跑 Docker 默认地址池耗尽，未进入测试；后续复用 `cluster_lab.network_plan()` 选择未冲突子网。全部失败/成功尝试分目录保存；结束仅停止本次新容器，保留卷和网络，不做全局清理。fixture 私有环境文件在退出时移除；密码不写入报告或交付。
