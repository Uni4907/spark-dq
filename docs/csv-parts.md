# 多份 CSV 分片受控注册

本功能接收2..16份CSV，逐份验证后按HTTP提交顺序生成一份独立、规范化的CSV数据集；不去重、不治理、不修改原文件。后续沿用规则→Spark→治理版本→复检→JSON报告闭环，可选原CSV、分片CSV或Parquet执行副本。原生Parquet上传仍未开放。

## 页面与接口

工作台“注册多份 CSV 分片”可一次选择多份文件。浏览器提供的文件列表顺序可能由文件选择器决定，系统以实际提交顺序为准；注册后展开“分片来源”核对顺序、记录数、字节数、SHA-256，并可下载每份原文件。

`POST /api/datasets/csv-parts`：multipart/form-data，重复字段`files`，每项一份CSV。不接受路径、目录、归档或客户端来源清单。成功返回普通数据集详情及`source`，其中version=1、format=CSV_PARTS、order=REQUEST、columns、rowCount、canonicalSha256、files有序列表。各条目含服务端001.csv等相对路径、清理路径前缀后的显示名称、size、sha256、rows。

`GET /api/datasets/{id}/download`下载合并规范CSV；`GET /api/datasets/{id}/sources/{ordinal}/download`按1起始序号下载原分片，下载前验证真实路径、大小和SHA。不存在的序号/普通数据集返回404，已绑定源文件损坏返回409。客户端不能通过序号指定路径。

## 数据契约与容量

- 所有分片UTF-8/RFC4180，各自允许BOM；字段名与顺序必须完全一致，英文字母开头的字母数字下划线、最多64字符/100列；禁止重复字段、NUL、超过65536字符的单元格和列数不齐。
- 每份必须含表头且非零字节；允许仅表头分片，但合并后至少一条记录。2..16份文件，清理后的名称唯一、最多200字符、无控制字符。
- 原文件实际读取总量≤20MiB，合并后实际写入也≤20MiB。后者独立限制规范化全引号CSV的膨胀；HTTP总请求上限沿用21MB。不会信任上传声明的大小。
- 跨分片重复、行顺序、Unicode、引号内换行、空文本、纯空格均保留。合并文件按RFC4180全引号输出，无BOM；原分片字节、换行、BOM不变。统计沿用csv-v2：\N表示缺失，空文本与纯空格另计；不是任意CSV空值方言转换。

## 持久化与失败

V4仅向datasets增加可空`source_manifest_json`列；旧记录保持NULL，旧详情/列表/任务/报告形状保持兼容。合并CSV仍在/data/raw/{id}.csv，源分片在/data/sources/{id}/001.csv等只读文件。来源清单在注册时绑定合并SHA、字段、总记录数和逐文件指纹，没有编辑接口。既有任务快照冻结的是合并CSV的SHA；不会重新读取来源分片来执行检测。

专用CsvImports服务提供事务边界，避免给旧Datasets服务加代理导致既有调度直接访问字段失败。验证或事务失败不留下可见的半注册数据集；已写的来源诊断目录、可能的未注册规范CSV保留，巡检列为警告，不自动删除。仅成功路径生成的combined.pending.csv临时合并文件会被移除。注册为有界同步请求，暂未加入后台导入任务、幂等重试或自动清理；响应丢失时先查数据集，避免盲目重复提交。

治理产物为独立CSV版本，不假称重新上传多份来源；通过父版本关系追溯至原始分片注册数据。执行副本与治理/复检快照机制不变。

## 备份与恢复

storage.py兼容无V4列的旧库；发现新列后对账来源清单与合并SHA/字段/行数，逐一核对源分片的有序路径、大小、SHA和总量。来源丢失/损坏阻止完整备份通过，孤立失败目录作为诊断警告。现有SQL+全部文件+实际Java应用备份和新卷隔离恢复覆盖来源工件。

升级前先一致备份V3，V4只增加列，不重写数据。旧V3程序不能直接连接V4库；不能删列或repair/clean迁移降级。如需恢复，先新卷隔离恢复升级前整组备份，核验后决定切换，不能覆盖现有卷。

## 可复现验收

~~~bash
timeout 900s python3 tests/csv_parts_e2e.py --base http://127.0.0.1:18080/api
timeout 90s python3 tests/csv_parts_e2e.py --base http://127.0.0.1:18080/api --check /absolute/multipart-fixture.json
~~~

首次验收只新增合成样本、任务和治理版本；--check只读，核对来源下载、合并SHA、任务与报告跨重启/恢复一致性。Java CsvPartsTest覆盖特殊值和真实字节限额，Python test_csv_parts_storage验证来源对账。故意损坏/修复只允许恢复克隆中的新合成源文件，不得对主环境运行。

本阶段仍是有界单机系统，没有原生Parquet上传、异构schema合并、目录扫描、ZIP上传、集群提交或TB级规模结论。
